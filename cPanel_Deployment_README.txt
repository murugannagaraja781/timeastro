==================================================
MyAstroLabs - cPanel Deployment Guide
==================================================

இந்த README பைல் மூலம் உங்கள் வெப்சைட்டை cPanel-ல் எப்படி லைவ் ஆக்குவது என்பதை எளிதாக அறிந்துகொள்ளலாம்.

--------------------------------------------------
உங்களிடம் உள்ளவை (Your Files)
--------------------------------------------------
1. deployment_package.zip - இதை நீங்கள் cPanel-ல் அப்லோட் செய்ய வேண்டும்.
2. இந்த README பைல்.

==================================================
Step 1: பைல்களை Upload செய்வது
==================================================
1. உங்கள் cPanel-ல் Log in செய்யவும்.
2. "File Manager"-ஐ கிளிக் செய்யவும்.
3. இடது பக்கம் உள்ள "public_html" போல்டரை கிளிக் செய்யவும்.
4. மேலே "Upload" என்பதை கிளிக் செய்து, "deployment_package.zip"-ஐ அப்லோட் செய்யவும்.
5. அப்லோட் ஆனதும், File Manager-க்கு திரும்பி வந்து, அந்த .zip பைலை ரைட்-கிளிக் செய்து "Extract" கொடுக்கவும்.
6. பைல்கள் சரியாக public_html-க்குள் வந்துவிட்டதா என சரிபார்க்கவும்.
7. இப்போது அந்த .zip பைலை டெலீட் செய்துவிடலாம்.

(முக்கியம்: File Manager Settings-ல் "Show Hidden Files" டிக் செய்திருக்க வேண்டும். அப்போதுதான் .htaccess பைல் தெரியும்.)

==================================================
Step 2: Database உருவாக்குவது
==================================================
1. cPanel மெயின் பேஜில் "MySQL® Databases"-ஐ கிளிக் செய்யவும்.
2. Create New Database: ஒரு பெயரை (உதாரணம்: astrodb) டைப் செய்து Create கொடுக்கவும். (முழு பெயரையும் குறித்து கொள்ளவும்).
3. Create New User: கீழே சென்று ஒரு Username மற்றும் Password கொடுத்து Create கொடுக்கவும்.
4. Add User to Database: நீங்கள் உருவாக்கிய User-ஐயும் Database-ஐயும் தேர்ந்தெடுத்து Add கொடுக்கவும். அதில் "All Privileges" என்பதை டிக் செய்து Save செய்யவும்.

==================================================
Step 3: Database Data-வை Import செய்வது
==================================================
1. cPanel மெயின் பேஜில் "phpMyAdmin"-ஐ கிளிக் செய்யவும்.
2. இடது பக்கம் உங்கள் Database-ஐ கிளிக் செய்யவும்.
3. மேலே "Import" என்பதை கிளிக் செய்யவும்.
4. Choose File-ஐ அழுத்தி, நீங்கள் extract செய்த "api/database.sql" பைலை அப்லோட் செய்யவும்.
5. கீழே "Go" என்பதை கிளிக் செய்யவும்.

==================================================
Step 4: Database Connection மாற்றுவது (Backend Link)
==================================================
1. மீண்டும் File Manager-க்கு வரவும்.
2. public_html/api/config.php என்ற பைலை ரைட்-கிளிக் செய்து "Edit" கொடுக்கவும்.
3. மேலே உள்ள வரிகளை உங்கள் cPanel விவரங்களுக்கு ஏற்ப மாற்றவும்:

   define('DB_HOST', 'localhost');
   define('DB_USER', 'உங்கள்_cPanel_DB_Username');
   define('DB_PASS', 'உங்கள்_cPanel_DB_Password');
   define('DB_NAME', 'உங்கள்_cPanel_DB_Name');

4. Save Changes கொடுக்கவும்.

==================================================

Super Admin Dashboard-க்கு செல்ல yourdomain.com/admin என டைப் செய்யவும்.
